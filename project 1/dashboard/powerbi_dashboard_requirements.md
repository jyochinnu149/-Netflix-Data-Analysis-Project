# Power BI / Tableau Dashboard Requirements

## Dashboard Objective

Build an interactive dashboard to visualize Netflix catalog trends and support business storytelling.

## KPI Cards

- Total Titles
- Movies
- TV Shows
- Countries
- Genres
- Average Release Year

## Production Trends

- Year-wise content trend
- Monthly content addition trend
- Release year distribution

## Content Analysis

- Movie vs TV Show comparison
- Top countries producing content
- Top genres
- Rating distribution

## Filters

- Content Type
- Release Year
- Country
- Rating
- Genre

## Visual Components

1. KPI cards
2. Line chart for year-wise trend
3. Bar chart for top countries
4. Bar chart for top genres
5. Treemap or bar chart for ratings
6. Pie or donut chart for movie vs TV show share
7. Slicer panel for filters

## Suggested Data Fields

- type
- title
- country
- release_year
- rating
- listed_in
- duration
- date_added
- director

## Design Suggestions

- Dark theme or Netflix-inspired theme
- Use red, black, white colors for visual style
- Keep labels readable and large
- Use consistent fonts and spacing
- Focus on storytelling rather than decoration

## Dashboard Story

The dashboard should answer:

- Which content types dominate Netflix?
- Which countries contribute the most titles?
- Which genres are growing?
- How has Netflix content expanded over the years?
- Which ratings are most common in the catalog?
